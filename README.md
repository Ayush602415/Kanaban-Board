# Taskflow — Kanban Task Management App

Taskflow is a modern, responsive Kanban task management application that helps users organize their work, manage priorities, and track task progress through a simple visual board.

## 🚀 Features

- **Kanban Board:** Organize tasks into three columns — To Do, In Progress, and Completed.
- **Create Tasks:** Add new tasks with a title, description, category, and priority.
- **Edit Tasks:** Update task details whenever needed.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Update Task Status:** Change task status directly from the task card.
- **Search Tasks:** Find tasks using their title or description.
- **Filter Tasks:** Filter by category, priority, and status.
- **LocalStorage:** Persist tasks across browser refreshes.
- **Responsive Design:** Adapt the interface to different screen sizes.
- **Dark Theme:** A clean, modern dark UI with an indigo accent.

## 🛠️ Tech Stack

- **React** — UI development
- **Tailwind CSS** — Styling and responsive layouts
- **React Router** — Client-side navigation
- **Lucide React** — Icons
- **LocalStorage** — Client-side task persistence
- **Vite** — Development server and build tool

## 📋 How to Use

1. Create a task using the **New Task** button.
2. Add its title, description, category, and priority.
3. View tasks on the Kanban board.
4. Change a task's status as work progresses.
5. Use search and filters to find specific tasks.
6. Edit or delete tasks when needed.

## 💾 Data Storage

Taskflow uses browser LocalStorage to save tasks.

- No backend or database is required.
- Tasks remain available after refreshing the page in the same browser.
- Data is not automatically synchronized across browsers or devices.
- Clearing the browser's LocalStorage can remove saved tasks.


## 🎯 Project Objective

The objective of Taskflow is to provide a simple and intuitive way to organize tasks, prioritize work, and visualize progress using the Kanban methodology.
